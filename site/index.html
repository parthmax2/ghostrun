Deterministic replay

The first run records real LLM HTTP calls to a local .ghostrun_cache/; every run after replays them instantly. Zero API cost, zero latency, zero flakiness.

Semantic assertions

Assert on meaning (contains_intent, tone_is, â€¦), graded by a local Ollama model by default. Your prompts and data never leave your machine.

Regression tracking

Snapshot runs and diff them: classify every assertion as regression / fix / stable / added / removed, plus output-drift similarity.

Native to pytest

No cloud dashboard, no custom CLI to learn, no dataset to author by hand. Auto-registered as a pytest plugin â€” just pytest.
