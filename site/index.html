How GhostRun Works in 3 Simple Steps

Everything you need to ship confident, production-grade GenAI apps with zero API flakiness.

Step 1

1. Record Once, Replay in 0.04s

Wrap your function in @ghostrun.record. The first run records the real OpenAI call; subsequent runs replay in 0.04s offline for $0.

@ghostrun.record(model="gpt-4o-mini") def test_support_reply(): reply = call_support_ai("Where is my refund?")
Step 2

2. Assert on Meaning (Not Exact Strings)

LLM outputs change slightly every run. Assert on semantic intent and tone graded by a free, local Ollama judge.

ghostrun.expect(reply).contains_intent("apology") ghostrun.expect(reply).contains_intent("refund policy") ghostrun.expect(reply).tone_is("empathetic")
Step 3

3. Self-Healing Prompts (`ghostrun craft`)

If your prompt fails, don't guess fixes. GhostRun uses Bayesian optimization to automatically find winning instructions for you.

crafted = ghostrun.craft( name="support_bot", signature="query -> reply, tone", examples_path="dataset.jsonl", budget=10 )
