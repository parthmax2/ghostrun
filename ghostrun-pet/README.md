# GhostRun ChatGPT Desktop Pet

Custom interactive status pet for the ChatGPT Desktop App.

## Installation Instructions

### Windows
1. Open File Explorer and navigate to your ChatGPT pets folder:
   `%APPDATA%\com.openai.chat\pets\`
   *(Or search for `com.openai.chat` inside `%APPDATA%` and locate the `pets` folder)*
2. Create a new folder inside named `ghostrun`.
3. Copy `spritesheet.png` and `pet.json` from this directory into that folder.
4. Restart the ChatGPT Desktop App.
5. Go to **Settings > Pets** (or click your profile -> Pets), select **Refresh**, and select **GhostRun**.

### macOS
1. Open Finder, press `Cmd + Shift + G` and type:
   `~/Library/Application Support/com.openai.chat/pets/`
2. Create a new folder named `ghostrun`.
3. Copy `spritesheet.png` and `pet.json` into that folder.
4. Restart the ChatGPT Desktop App.
5. Open **Settings > Pets**, click **Refresh**, and choose **GhostRun**.
